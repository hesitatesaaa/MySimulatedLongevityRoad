# 我的模拟长生路 0.7.0

WorldBox build 115 / NeoModLoader 模组。0.7.0 接入生灵栏目、玄黄族文明及六种战斗职业。

生灵栏目首页有妖兽、仙道人物、玄黄族三个入口，点击后在同一栏内展示对应放置按钮，返回首页或重新打开即可重新选择。原版全部智慧生物与其他生物入口保持可见。玄黄族沿用原生人类生活与文明行为，具有男女基本形象、儿童、士兵、国王、领袖、老年和僵尸身份，三种朝向结合左右翻转，并以独立衣服蒙版呈现国家色。文明资源包括 19 项独立建筑和三类船只，六项公共建筑继续使用原版资源。

剑修、武修、术修、符修、阵修和灵契师各有五阶主动与被动技能。66 个职业技能图标为 64 像素，30 个主动技能使用独立 24 帧动画；灵狼、岩龟、雷隼和灵鹿使用各自外观。技能在战斗中自动施放，修士档案下方可切换列传和本职十项技能说明。

默认交付压缩玩家包，包含完整运行源码与有效资源。PNG 最多 256 色，大图标最长边 256，仅处理包内副本；资源来源、帧映射和哈希见 resources/living-resources.json。开发素材和测试探针不进入玩家包。

建议先用新世界测试，并备份旧存档。安装、构建和实际验证范围见 [开发与验证说明](resources/LOCAL-DEVELOPMENT.md)，本轮实施和验收状态见 [0.7.0 实施记录](resources/living-beings-implementation.md)。离线资源检查及编译不代表交互式视觉审看或性能验收。

兽潮控制采用墨青卷册，分为兽潮调控、手动召潮、兽潮纪事；数值支持输入与加减，召潮操作固定在底部，正文支持拖动滚动条。玄黄族正常放置成年单位后沿用原版 AI 自主建国。男女七类身份各有独立生成的三方向四帧泳姿，水线以下透明；职业技能按钮有配套艺术字，重复点击可返回原信息。
