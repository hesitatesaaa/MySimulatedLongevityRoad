# 我的模拟长生路 0.6.0

WorldBox / NeoModLoader 模组。当前工作区是本地精简开发版，未提交、未推送，不代表 GitHub 上的旧发布附件。

当前增加四职斗法开发预览：剑修、体修、五行术修、御兽师，16门新技能、法门卷、传承与战斗领悟、主职切换、灵契投影及三级毁地设置；仅新增4张职业特质图标。实现与验收边界见 [四职斗法说明](resources/battle-combat-implementation.md)。尚未进行本版Unity启动及100／500／1000单位实测。

本版接入 62 套形态、1374 张动画帧、38 个角色图标、111 个物品图标及 48 个法术阶段图集，包含从 generated_images 补入的 9 张未判废最新修复图。图片继续审看按用户要求取消。

当前动画仅保留最终新版的一份运行 PNG。全部帧等比缩小，保留完整构图、透明度和颜色；具名兽形分三档，其他兽形按物种最低兽潮等级分五档，人形显示体型与西幻精灵旅者一致。

开发者包包含当前源码、资源、构建与验证工具、来源哈希及提示词；已删除重复原图、旧动画、失败候选、回滚文件和旧包。缩放后的原图细节有所减少，游戏内显示与性能未重新实测；此前实测记录仅作为历史资料。

仅适用于新存档。安装、构建和实际验证范围见 [开发与验证说明](resources/LOCAL-DEVELOPMENT.md)。
