## 入道与游玩流程

游戏内“模组介绍／入道指南”提供十章：入门与倍速、时代修行、生灵与玄黄族、妖兽兽潮、本命神通、功法传承与势力家族、探索资源与炼制、战斗职业与普通法术、乾坤袋与天玄镜、还真与纪事。章节写明入口、条件、操作、自动推进和限制；窄窗口目录支持横向滚动，正文独立滚动。

- **修行与时代：**选中人物查看资质、灵根、体质、境界和真元。灵根通常在五岁判定，跳过年龄时补判。修士按年度自主积累真元，再按新旧法各自条件突破炼气、筑基、金丹、元婴、化神、合道、长生；达到真元门槛不保证突破。同法人数、世界状态、功法与物品影响效率。
- **文明与生灵：**从生灵栏目进入玄黄族、妖兽或仙道人物，返回首页重新选类。玄黄族首次手动放置，之后沿原版生活、繁殖、游牧、建国及城市AI发展；玩家包采用正常建设流程，手动建筑按钮属于开发者工具。
- **妖兽与兽潮：**21种普通妖兽通过兽潮或手动放置出现，不再自然生成；水生妖兽在水域生成，其余在陆地。兽潮七级随世界境界解锁。调控窗口可设置间隔、数量倍率、单次数量、最高等级和总量上限，查看召潮结果与纪事；六级以上发布重要公告。**手动召潮点击后立即反馈请求**；位置索引尚未准备完时优先分帧准备，就绪后引动，不受世界解锁等级限制，但仍受单次上限、自动妖兽总上限和同时活动场次约束。元婴化形保留普通妖兽身份，不开放普通法术学习。**妖兽出生不带乾坤袋**，人物窗口没有储物页；本版不读取旧模组存档。
- **世界标识尺寸：**模组生灵的收藏星标、攻击与任务提示、旗帜、状态图标和选中标记统一使用原版大小，不随放大后的立绘一起变大；原版生灵保持自身缩放。
- **功法、宗门与家族：**玄黄仙录查看师徒、典籍、功法及势力；十宗与新法时期的万仙盟、五老会随时代推进。家族页展示家主、成员、家库、传承、纪事与城市影响，每五年自动结算；玄黄舆图展示城镇主家和影响力。
- **探索与生产：**天下纪事和舆图提供遗迹、秘境、洞天、灵石与灵材记录。探索可能获取传承及材料，也可能受伤、死亡；境界和体质影响结果，秘境最终死亡率最高40%。炼丹、炼器、制符是生产技艺，按职业品阶与材料自动炼制，区别于六种战斗职业；妖兽通材和物种专材参与相应配方。
- **战斗、物品与交易：**人物窗口查看职业、普通法术、乾坤袋。六种战斗职业各五阶主动与被动技能；普通法术逐年研习，十年结算和实战施放可积累升级经验。技能受境界、灵力、冷却、目标和道具条件约束。乾坤袋按法宝、丹药、符箓、材料、传承典籍、法术分类查看和操作。天玄镜展示挂单、最新上架、成交记录，人物按需求自动交易，使用灵石或贡献，玩家无需手动下单。
- **还真与历史：**等待还真自然降临或赋予特质，确认宿主并保存世界。首次绑定获得80点空间灵蕴，建立锚点消耗80点，最多三枚，满额先选替换目标；可自动锚定。手动回溯选归途锚点并二次确认；当前世进入前世档案，可按名额选择实际拥有的遗产。人物列传、家族纪事、天下纪事分别记录个人、家族和世界变化。
