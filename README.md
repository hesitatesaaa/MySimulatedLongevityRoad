# 我的模拟长生路

> 当前源码版本为 **0.5.4**。沿用 0.5.3 的架构、玩法、经济、界面和资源；本版提高年度结算吞吐并修复零速积压。仅支持新世界。
>
> 0.5.0 的架构文档记录了所移植功能的来源；本版世界存储继续使用基线的 ArchitectureV1。配置中打开“性能监控”后，可在“性能报告”中重置和导出当前运行数据。

WorldBox 模组，作者：溪上翁、kinght。当前源码版本 `0.5.4`，`mod.json` 中的目标游戏构建为 `115`。

- `InterestingTrait.sln` / `InterestingTrait.csproj`：原有解决方案与 C# 项目，目标框架为 `netstandard2.1`，可由 WorldBox 的 Unity/Mono 运行时加载。

- `scripts/Generate-ItemCatalog.py`：依据参考 DOCX 重新生成 ID 驱动的物品目录。

- `scripts/Audit-Beast-Sprites.py`：检查全部 62 个生效形态的五动作资源与基本尺寸；通过该检查不代表动作绘制、主体完整性及实机显示已验证。

## 开发与构建

项目目标框架为 `netstandard2.1`，用于 WorldBox 的 Unity/Mono 运行环境。项目不会把 WorldBox、Unity、Harmony 或 NeoModLoader DLL 提交到仓库。

默认依赖目录是 `D:\owl\gameversion\0_51_2_imported\worldbox_Data`，也可以通过 `WorldBoxDataRoot` MSBuild 属性指定其他安装位置。

```powershell
dotnet build .\InterestingTrait.csproj -c Release -p:WorldBoxDataRoot=D:\owl\gameversion\0_51_2_imported\worldbox_Data -p:_EnableDefaultWindowsPlatform=false
```

构建结果位于 `bin/Release/netstandard2.1/MySimulatedLongevityRoad.dll`。发布的源码包保留 `InterestingTrait.cs`、`code/` 和 `GameResources/`，供 NeoModLoader 加载。

如果只需要检查项目文件而没有 WorldBox 依赖，可使用：

```powershell
dotnet msbuild .\InterestingTrait.csproj -getItem:Compile -nologo -p:_EnableDefaultWindowsPlatform=false
```

日常修改只打开发者包；正式更新 `mod.json` 版本号时，同次打开发者包和玩家包。开发者包包含人物编辑器源码，可使用 F8 和开发者入口；玩家包省略编辑器后，相关入口和测试按钮不会显示。`references/` 始终不加入编译项。

```powershell
pwsh -NoProfile -File .\scripts\Test-Project.ps1 -Mode Package -ChangeTag 开发验证
# 仅版本号更新时使用：
pwsh -NoProfile -File .\scripts\Test-Project.ps1 -Mode Package -ChangeTag 版本更新 -VersionUpdate
```

## 原版 WorldBox 导入

本项目发布包沿用现有的源码型 Mod 结构。请先安装与游戏版本匹配的 NeoModLoader，然后把压缩包内的模组目录解压到以下任一 NML 模组目录（只选一个）：

```text
<WorldBox>\mods\
<WorldBox>\worldbox_Data\StreamingAssets\mods\
```

解压后的目录可以保留外层文件夹，但 NML 搜索到的模组目录必须直接包含以下文件和目录：

```text
mod.json
icon.png
InterestingTrait.cs
code/
GameResources/
Locales/
```

不要把 ZIP 文件本身放进 `mods`，也不要多套一层目录。若之前安装过旧版，请先删除旧的 `我的模拟长生路` 文件夹，再解压本包；两个文件夹同时存在会触发相同 GUID 冲突，NML 只会加载其中一个。该发布格式不要求 ZIP 内携带 DLL；直接运行原版 WorldBox 时请确认游戏的实验性模组开关已开启。

安装支持 `netstandard2.1` 的 .NET SDK，并准备与游戏版本匹配的 WorldBox 与 NeoModLoader 依赖。外部 DLL 未包含在压缩包中，也未加入仓库。

`references/WorldBoxGameDecompiled/` 是单独导入的 WorldBox 反编译参考树，供搜索 `Actor`、`MapBox`、`SaveManager` 等原版类型、字段和方法使用。它不是模组依赖，已从项目编译项中排除；发布模组时不要把该目录复制到玩家的 mods 目录。

两种源码包都包含入口源码、`code/`、`GameResources/`、`Locales/`、配置、模组元数据和本 README 安装说明。开发者包另含人物编辑器源码；玩家包排除它。`bin/` 与 `obj/` 是本地构建缓存，不属于任何包。依赖 NeoModLoader 与游戏自带程序集由游戏提供。

## 0.5.0 调度与性能

年度工作使用保存游标的分步调度器，人物、世界、市场和家族工作可跨帧续跑。年度角色不再受每帧 80 步的数量上限限制，改用共享时间预算和 4096 次操作保护上限。积压时自动调整模拟速度；零速期间年度结算继续运行，异常阻断或 10 秒未推进时退到 0.25 倍兜底。玩家主动暂停状态保留。

保留连续年度等待状态修复和首次入道真元防重发。年度人物工作受基线预算限制；当年首次入道只获得一次基础修炼结算。

法术特效使用 0.5.2 的 26 张新版图集：范围攻击每次只在施法者身上显示一次；单体法术跟随目标；自用和群体辅助显示在施法者身上。法术伤害、状态、地形效果、耗蓝和冷却仍按原目标结算。

## v0.3.5 更新摘要

- **委托与风险：** 十宗各有六种分境界任务，10～16 年委派 1～3 人；万仙盟、五老会各有十二种任务，维持 6～12 年委派 1～4 人。逐境界独立判定失败及失败后死亡，失败不结算报酬。
- **修仙家族：** 修士按父系、母系、原版家族顺序归族，记录家主、成员、家库、传承与城市影响；五年一次族费和后辈扶持，可在家库与成员间调拨灵石及未装备物品。
- **界面：** 仙道纪元另设“十大仙宗”页，两时代均有“修仙家族”与“玄黄舆图”页；人物信息显示资质、家族与当前宗门，排行榜将可筛选特质合并在一个栏位。
- **玄黄异禀：** 17 种体质各有独立贴图与说明，原版属性、年度真元、法术研习及升级、秘境探索和破境效果按体质生效。出生时抽中特殊体质的总概率为 0.2%，至多取得一种；旧档人物不重抽。
  - 传奇体质各为 0.008%：天生仙体、先天道体、天妒·破妄目、天妒·不朽骨、天妒·怒焰体、异兽融炉体、征伐圣体、万道锻体、百折复元体。
  - 史诗体质各为 0.016%：通灵宝体、水灵体、先天弱体、阵灵圣体、上古妖血、阴阳玉伴生体、共修益元体、幽族灵躯。
- **入口与档案：** 力量栏的设置入口旁有独立“恢复默认设置”按钮；天下纪事的舆图按当前势力着深色。修士列传打开与重新照录时刷新在世人物。绝嗣家族清算家库，实物排队进入天玄镜。

- **旧法仙宗与新法势力：** 旧法纪元设立十大仙宗并发布灵石委托；传法证道时十宗退场，过渡期由万仙盟承接事务，十年后五老会成立。十宗在仙道纪元专页展示，保留历史和宗门出身记录。
- **秘境与师徒：** 秘境探索死亡率按修士、秘境及体质计算并限制在 2%～40%；天地垂青者免于相关探索死亡。合格师父每年收徒成功率调整至约 5%，保留名额、境界及冷却条件。
- **天资与收藏：** 天地垂青改为全图唯一并可转移，提供多项属性和修行增益；天地垂青、神化天资、合道圣胎、长生道种持有者自动加入 WorldBox 收藏。
- **法术修炼：** 已学法术自动择优精进，可重点修炼多种法术；每十年经验总预算为 `12 + 悟性÷8`，施法经验计入同一预算。法术按可学境界排序，乾坤袋只显示已学法术。
- **法术卷轴：** 26 种法术加入分境界配方、灵符纸与法则材料，卷轴定价提高；修士低概率在天玄镜补购材料并制作，合格卷轴可自动研习。未学卷轴不作为乾坤袋物品展示。
- **法术录与特效：** 人物信息界面的猫宝入口旁新增法术录，可由玩家为该人物直接授法；法术特效绘制尺寸扩大并提高可见度。
- **界面与设置：** 扩大天玄镜窗口和文字，更新悟性图标；力量栏在设置入口旁提供恢复默认按钮，只重置本模组设置。
- **职业炼制：** 炼丹师、炼器师、制符师统一允许制作自身品阶及低一阶物品；黄阶不得炼制凡阶，所有职业均禁止跨两阶及以上向下炼制。
- **兼容性：** 版本为 `0.3.5`；不提供旧存档迁移，请使用新世界。游戏内加载状态尚未验证。

- 新增三种职业、六类乾坤袋、材料探索、制作、使用与贡献度交易；物品目录收录 38 个 ID。
- 新增独立入道指南、乾坤袋及天玄镜窗口和贴图；修士榜按境界序号排序，玄黄仙录正文显示滚动条。
