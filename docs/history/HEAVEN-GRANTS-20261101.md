# 玄黄天道双按钮交付记录（0.8.4）

## 使用方式与边界

在人物特质编辑列表的“玄黄天道”分组中，“天地垂青”后增加“天赐圆满”和“天授道书”。两者均为添加后执行、随即移除的操作特质，可再次点击；不自然生成、不遗传，也不提供永久锁定。

- 天赐圆满：仙缘、资质、悟性、心境的原始值设为100，并记为已经判定仙缘。同步资质特质，不主动生成灵根档案、修行路线或境界。无路线凡人继续遵守原有显示及生效规则；心境仍会受到后续事件影响。
- 天授道书：使用现有四部合道功法，优先匹配旧法的法则标签，再按固定排序与角色稳定哈希选择。已有有效合道及以上传承时保留原法和进度。旧法使用旧法标识，无路线者仅保存新法道书；换低阶功法时重置功法参悟，不改变境界、真元或突破进度。

两按钮共用 `GameResources/trait/MclslTiandaoEdict.png`。正式图标为32×32透明RGBA、14种不透明颜色、硬像素边缘；生成工具为 `tools/build-tiandao-edict.py`。放大预览只存放于忽略的build目录，不进入玩家包。

## 实现复核重点

保留现有字符串及资产两种addTrait补丁，共用特质路由；已移除的操作特质不能在外层字符串补丁再次执行。同步资质与移除操作特质使用现有路由抑制机制。

资质同步增加内部可选参数，默认保持现有行为；“天赐圆满”使用不进行身份协调的路径，避免原有唤醒逻辑生成凡人灵根档案。功法标识写入继续使用既有数据入口及同修索引通知，不额外提交第二次通知。

本轮不增加存档字段、迁移、玩家配置、公开API、全世界扫描、独立调度器或逐帧轮询，也不改变共享时间预算。仅支持当前格式新存档。
