# 原始预载方式与加载优化

## 本次结果
- 已恢复全部125张特效图集到GameResources/effects，三个使用端恢复SpriteTextureLoader.getSprite，移除延迟加载类及其清理调用。
- 保留PNG原滤波方式和元数据进行无损重压缩，48张变小，125张合计从40,351,350字节降为39,842,800字节，节省508,550字节（约1.26%）；所有RGBA像素、尺寸、帧布局不变。
- 本地Pillow内存解码五轮交替对照，中位数从340.07ms降至327.81ms；这是代理测试，不是Unity启动秒数。
- 常规最强PNG重编码在代表法术图集上出现明显解码减速，未采用该方案。未降低分辨率、颜色数或特效质量。
- 化形站立高度改为离线元数据，删除约25次启动校准用的额外PNG解码和临时纹理上传。62组高度与PNG重新核对一致；人形PPU比例公式和最终绘制规则不变。

## 验证与限制
274个C#源码编译通过，0错误，既有警告保持。图集像素一致性、原路径125张覆盖、无延迟加载残留、站立高度元数据及ZIP哈希校验通过。PNG压缩不能减少解码后约331MiB特效RGBA数据；启动依然会加载它们。本轮未重启正在运行的游戏，没有实测最终启动耗时，不能承诺提速百分比。
