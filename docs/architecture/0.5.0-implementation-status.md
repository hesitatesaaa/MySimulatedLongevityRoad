# 0.5.0 重构实施状态（2026-10-03）

0.5.0 的运行架构、特殊体质规则、经济闭环、新存档、正式开发者编辑器和源码型 NML 加载均已落地。旧存档、旧性能限速补丁、重复调度配置、失效开发者打包脚本及旧内部适配入口不进入 0.5.0 运行路径。

已完成的关键不变量：

- 每个世界由一个 `MclslWorldContext` 持有领域状态；人物生命周期身份为世界运行 ID、人物 ID 与出生时间组合。
- 年度人物和世界工作保存阶段、实体及步骤游标；同一稳定操作 ID 不能重复发钱、扣款、成交或发放奖励。
- 体质资格逐人物调用原版 `isSapient()`，排除模组特殊实体；17 种体质从出生、编辑器、恢复和对账入口共用同一规则，获得后幂等确保完整灵根。
- 钱包、家库、订单和托管由 64 位账本及补偿事务提交；双币折算固定为 1 贡献度 = 2 灵石。
- 市场处理全部可售余量，卖家订单 10 年退回，公共普通库存直接使用卖家期限 × 2；职业滞销后以真实材料练习，不制造商品。
- ArchitectureV2 世界封套包含世界种子、运行 ID、快照代次和 SHA-256；还真锚点与世界代次配对；猫宝 v3 不携带可复制资产。
- UI 读取查询快照，窗口刷新不触发年度结算；性能报告保留实际年份推进与阶段耗时。

验证结果见 [0.5.0 验收报告](0.5.0-validation-report.md)，玩法入口与承接关系见 [0.5.0 玩法保留矩阵](0.5.0-gameplay-matrix.md)，逐文件处置见 [0.5.0 全源码处置清单](0.5.0-source-disposition.md)。
