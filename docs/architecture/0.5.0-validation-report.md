## NML 实机验证

在目标 WorldBox build 115 的独立 `StreamingAssets/mods/MCLSL_050_TEST` 目录由 NeoModLoader 编译源码。日志出现 `[我的模拟长生路]: Loaded` 和 `World Loaded`，未出现本模组 C# 编译错误。测试世界完成年度 42 推进。

首次性能日志发现 `Adventure` 单步约 117.03 ms。将一次遗府中 2～5 人的结算改为保存选中顺序、每帧处理一名探索者并在最后收尾后，同一存档重新源码加载，`Adventure` 为 0.93 ms。该轮其他首次年度阶段为 Prepare 1.22 ms、EraCycle 0.82 ms、Cave 1.64 ms、TechniqueLineage 4.86 ms、SectLifecycle 5.15 ms、FactionMission 1.80 ms、Family 3.13 ms；均低于“常规模组任务单次不超过 50 ms”的硬门槛。这里包含首次执行/JIT 成本，不等同于稳态 P95。

## 实机边界

当前自动化环境不能操控 WorldBox 地图编辑器来建立可重复的 1000/5000/10000 人口、新旧法、1 倍/20 倍速对照世界，因此没有伪造这些场景的平均帧时、P95/P99、GC 或实际年份推进数据。0.5.0 内置性能报告已经记录这些指标；正式对照需要在同一硬件按每组预热 5 分钟、采样 15 分钟、重复 3 次执行并导出报告。

已得到的实机证据证明源码能由 NML 编译加载，并消除了本轮实际发现的 >50 ms 探险尖峰；它不能证明尚未运行的人口矩阵达到“较 0.3.5 P95 降低 30%”的相对目标。
