# 0.5.4 逐帧重绘状态

当前 `GameResources/actors` 下的 62 组、1364 张五动作帧仍是旧版图集生成的素材。`Audit-Beast-Sprites.py` 只核对文件、透明度、基础尺寸和帧差异，不能证明造型完整、动作自然或逐帧独立绘制。

放置按钮已经读取各形态的 `spawn_icon.png`，旧图集裁切脚本已停用。但现有 62 个图标仍由待机图裁切，并非约定的独立绘图。`Build-Spawn-Icons.py` 现在只允许输出到预览目录，不再覆盖正式图标。

重绘交付要求：每个形态的 `main/idle_0..3.png`、`attack_0..5.png`、`walk_0..3.png`、`hit_0..3.png`、`death_0..3.png` 都应是单独绘制的完整 RGBA 图；同一形态采用一致的画布、脚底锚点和像素密度。检查最大展翼、角、尾、武器和特效姿态是否有安全边距。不得从动作图集合成后裁切，或将待机图平移、形变、淡出充作其他动作。

兽形世界缩放暂从 `0.18` 调到 `0.11`，并为本模组加载的精灵设置最近邻过滤；这只是离线修正，尚未在相同镜头下与西幻模组实测校准。参考包里 FireDrake 的 `idle_0` 是 320×320、主体约 168×89；RedDragon 是 480×400、主体约 384×174。这些是源图数据，不能代替同镜头的游戏内测量。

2026-10-08 增加 `scripts/actor_frame_provenance.json`，逐文件记录当前旧帧及图标的 SHA-256 和来源状态。`scripts/Audit-Frame-Redraw.py --report <路径>` 是严格重绘门禁：校验 62 组、1364 帧、62 个图标、画布边距、帧差异、脚底锚点、文件哈希，并列出触及画布边缘的非透明像素。`--structural-only` 只检查现有图像结构，不代表艺术验收。脚本无法自动证明动作自然或身体部位完整，这仍需逐帧和游戏内目视检查。

目前严格检查未通过：1364 帧均未有独立绘图来源，62 个图标均是待机帧裁切。尚无同镜头与西幻模组并排的 WorldBox 0.51.2 实机截图，也未确定图一的缺失来源。当前 0.5.4 不能作为重绘完成版发布。
