# 我的模拟长生路 0.8.1 更新报告

日期：2026-10-30。按最终要求只交付玩家包，采用 NML 源码加载，包含全部运行源码与资源。未重新启动游戏实机验收。

## 更新内容

- 修复清图、换图和读档边界的妖兽地形索引异常：清图前暂停并清空，世界就绪后恢复；过滤旧地块和越界坐标；地图尺寸变化后重建；未初始化地块保留游标重试。
- 保留此前显示修复：还真空间按钮及双列轮盘布局、介绍页对齐和滚动、神兽榜边框与页脚；人物标识、化形人形统一尺寸及受击/高亮；玄黄建筑阴影和风车比例。
- 保留兽潮独立分类及中繁文案、区域自然生成概率0.5%、特效2/3速度、本命神通特效半尺寸和现有档案排版。
- 保留恢复后的原始特效预载路径与化形站立高度离线元数据。
- mod.json 发行版本更新为0.8.1。存储目录仍为 MySimulatedLongevityRoad/0.8.0，存档键前缀仍为 mclsl.080.，本次不迁移或清空已有0.8.0档案。不支持0.7.0及更早格式。

## 体积原因与最终处理

用户指定的大新包为149,699,104字节（149.70 MB），小旧包为79,088,159字节（79.09 MB）。新包主要增加了83张1254×1254静态图标，图标相关目录的ZIP占用从约5.43 MB增至77.49 MB；不是动画帧数量翻倍。

- 全部2228张运行PNG均检查；其中83张静态大图标按现有小图标的使用方式处理，最终尺寸为128×128：17张、64×64：66张。尺寸逐张与旧包同名图标一致；保持当前新版图案，没有退回旧图。
- 以原图在32/64像素显示下为参照，在黑、灰、白三种背景检查；最低显示PSNR为33.633 dB，仅作误差记录。按最终要求，尺寸严格对齐旧包同名图标，不再为误差门槛保留更大尺寸。这是离线显示代理检查，不代表已经游戏内实测，也不代表缩图逐像素无损；放大到1254查看会减少细节。
- 未做颜色量化、减色或JPEG转换。其余PNG保持逐像素RGBA一致，包括全部动画的每帧、尺寸、帧顺序、透明度、图集布局、枢轴与时序。
- 对PNG重新无损编码、精简未使用调色板项；删除不参与显示的caBX来源签名块，保留显示/色彩及文字元数据。完整原图和原始来源信息仍留在本地工作目录，不进入玩家包。
- PNG总字节数由157,842,055降为74,731,758，减少83,110,297字节。ZIP使用标准Deflate最高等级9；不加入开发原稿、缓存、编译产物或测试依赖。

最终ZIP精确体积、与新旧包对比及SHA256见包旁《0.8.1-更新报告.md》和.sha256.txt；逐图片明细在resources/compression-0.8.1.json。

## 安装

关闭游戏，备份原模组和存档，将ZIP内MySimulatedLongevityRoad完整替换到mods；避免覆盖混装或同时启用两份。无需删除LocalLow或存档目录。适配WorldBox 0.51.2/build115及NeoModLoader。

## 复现

在独立副本上运行 tools/optimize-release-png.py --source 原工程目录 --output 副本目录 --reference-zip 旧玩家包路径，再同步资源清单并使用 tools/package-player.py --root 副本目录 --output 输出ZIP绝对路径。优化工具仅需Pillow；最终包和本轮最终压缩均不依赖imagequant。
