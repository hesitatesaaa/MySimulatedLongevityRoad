# 玄黄界面设计

## 设计来源与边界

本次界面重制研究了玄鉴仙族 `0.9.17` 中玄鉴仙鉴和排行榜的界面组织方式，提取了分卷导航、三栏榜单、固定表头、按需卡片、快照读取和统一色板等通用设计。模拟长生路保留自己的数据模型、修炼体系、筛选定义、窗口生命周期和还真逻辑，不依赖玄鉴仙族程序集，也不直接调用其代码。

## 玄黄修士榜

排行榜使用三栏布局：

- 左栏“筛选卷”：展示已选条件、所属国家、生灵种属和人物特征；
- 中栏“玄黄修士榜”：展示榜首摘要、灵根与境界选择、固定列名、人物卡片、数量和导航；
- 右栏“排序卷”：展示当前顺序、可选指标及人物搜索。

榜单数据由 `MclslRankSnapshotSource` 提供，窗口只筛选和排序快照。人物卡片按当前滚动区域生成，未进入视口的卡片不常驻。点击人物打开原版人物窗口，悬停继续使用人物原生提示。

人物卡片分为两行：第一行突出人物姓名与首要排序值，第二行显示灵根、额外状态和境界。显示文字必须是中文；内部筛选 ID 和排序 ID不作为界面文本。

## 玄黄仙录

仙录使用固定卷首、左侧分卷和单一正文滚动区：

- “天下纪事”：总览、原生诸国和时代纪事；
- “修行道统”：修行、突破、天地资源、修士生死和还真轮回；
- “山河万象”：天地变化、遗迹、秘境和其他世界现象。

仙道纪元与新法纪元继续使用各自的页面目录，分卷函数只改变导航呈现，不改变页面数据。正文不得再嵌套横向滚动条；长列表应限制渲染数量或使用已有快照。

“重新照录”只重建当前仙录快照。“修士榜”负责在释放仙录暂停与遮罩后打开排行榜，避免两个顶层窗口争夺输入。

## 统一色板

`MclslUiTheme` 保存卷面、面板、滚动区、金色框线、青蓝指标、玉色强调、正文和危险操作颜色。新界面应优先复用此色板，避免每个文件重复声明近似颜色。

## 中文命名

所有玩家可见内容必须使用中文：

- 模组功能入口、窗口标题、页面和按钮；
- 特征、物品、状态、筛选项和排序项；
- 提示、说明、空状态、错误信息及确认文字。

新增功能时必须同时更新 `Locales/ch.json` 与 `Locales/cz.json`。内部 ID、类型名、字段名和资源路径继续使用稳定 ASCII 名称；它们属于兼容接口，不应为了界面中文化而改名。若外部游戏内容没有可用中文本地化，界面应显示“未知特征”“未知生物”等中文后备文字，不直接暴露内部 ID。

## 性能约束

- 界面读取快照，不在每帧遍历全世界人物；
- 排行榜只生成视口附近的卡片；
- 窗口关闭时释放人物卡片引用和提示状态；
- 本地化、图标和色板应复用缓存；
- 新页面优先加入现有仙录分卷，不为单一统计再创建常驻窗口。
