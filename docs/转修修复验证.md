# 转修寿限与功法上限修复

旧法修士成功转修时记录已有基础寿限，新法计算取此记录与当前境界寿限的较大值，再分别结算夺寿收益和被夺寿惩罚。新法时代才入门的修士没有该记录，使用原有新法寿限。重复转换不叠加寿命，达到实际寿限仍会死亡。

换法入口使用实际获得的传承定义同步上限，并保留已有合法提升和当前境界。已知固定功法及其异法的错误缓存可在读取上限时修复；残缺传承、自创分支和未知功法不会被套用母法的高阶上限。

## 自动验证

统一验证入口会运行 `tests/CultivationTransitions`，直接编译运行时的身份切换、寿命、功法上限和年龄规则；WorldBox 对象与无关副作用使用替身。此验证不等同于游戏存档复现。

```powershell
pwsh -NoProfile -File scripts/Test-Project.ps1 -Mode Build -NoRestore -WorldBoxDataRoot 'D:\owl\gameversion\0_51_2_imported\worldbox_Data'
```

新环境首次构建去掉 `-NoRestore`。新增寿限字段进入还真补充整数状态白名单；旧快照缺少该字段时恢复为零，不从角色当前数据推测历史寿限。既有存档中已经转修且没有原始记录的角色不会被补造旧法寿命，已死亡角色不会复活。
