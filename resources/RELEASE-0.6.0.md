# 我的模拟长生路 0.6.0 预发布

本版接入62套角色形态、1374张独立动画帧和38张专用放置图标。运行帧保留当前独立原图的原生PNG字节，不缩放、裁切或重新编码。已取消补绘的攻击、受击动作使用现有动作或待机兜底。

同时包含旧目录已接入的111张物品图标、16种法术的48个阶段图集及配套玩法代码，包括21种妖兽和75项配方。物品图标和法术图集沿用其原有安装版本及转换记录；角色独立帧的原生PNG规则不追溯修改这些既有图集。

## 安装与升级

适用目标为 WorldBox build 115；编译依赖取自本项目使用的0.51.2游戏目录。需要已安装、与游戏版本匹配的NeoModLoader；本包不包含游戏、Unity或加载器依赖DLL。

下载player包，解压得到 `MySimulatedLongevityRoad` 文件夹，将整个文件夹放入NeoModLoader的模组目录。确保 `mod.json` 位于该文件夹第一层，不要多套一层同名目录。本版沿用源码加载，不需手工放入编译DLL。

升级前退出游戏并备份原模组目录及存档，将旧模组目录移出加载目录后再放入新版，避免同一GUID加载两次。不要把新版文件直接覆盖旧目录。卸载时退出游戏，移出该模组目录即可；保留备份以便恢复。

首次体验请新建世界。本版不承诺旧存档兼容验证通过。
