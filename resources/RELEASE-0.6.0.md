# 0.6.0 发布说明

安装 NeoModLoader，将玩家包中的 MySimulatedLongevityRoad 文件夹放入游戏 mods 目录，避免重复安装。测试版本为 WorldBox 0.51.2，目标 build 115。本版仅适用于新存档。

动画和人型动画已按当前清单接入，包括此前修复及 generated_images 中可明确对应、未判废的最新修复。历史原图、失败重试及回滚记录保留在开发者包。

用户已认可现有测试范围并要求停止追加测试。实际完成 62 形态尺寸验证、38 个按钮验证、100/500/1000 单位各 120 秒原生渲染测量，平均帧率分别约 29.97/59.62/56.70 FPS，三档原生覆盖率最低均为 100%。测试硬件为 GTX 1660 Ti 6 GiB，1920×1080；原生纹理缓存上限 2 GiB。

持续运行记录为 1140.96669 秒，约 19 分钟，未完成 20 分钟流程。最终匹配基线及额外完整穷举未重跑。独立的 1000 妖兽新档重载在年龄规则修复后全部通过。受控玩法证据与各次原始报告保留，未将未完成的报告改写为通过。范围和证据哈希见 runtime-acceptance-0.6.0.json。

正式构建及资源完整性检查通过。压缩包执行 CRC 与 SHA256 校验；公开游戏日志脱敏 Steam 账号标识，本地原始记录保持原样。
