# 0.8.6 灵根人口配额第二轮优化记录

## 实现

- 增加内部RootPopulation变更位，沿用主线程与并行交接；灵根主属性、属性集合、数量变化才为普通数据写入附加此标记。
- 灵根特质的增删（包括两个添加重载）、物种资产/亚种变化、智慧资格缓存变化、年龄跨过5岁和完整登记通知继续核对。功法、职业、资源、名字和城市变化不再因为通用成员通知重复查灵根。
- 登记统一由All通知核对，移除登记内部和年度登记回调的重复Observe。原生年龄快照对比已记录的5岁门槛，不因首次原生通知再次核对已登记人物；4→6岁也能捕获。
- 每个候选集中读取一次资格、年龄和实际灵根，用同一状态更新计数与进行选择；赋予后立即核对。妖兽原判定保持。
- 年度校正先排除死亡、未满5岁、妖兽及无资格者；只有统计分母成员读取实际灵根。保留一年一次分帧校正和原修炼候选入队，不新增扫描。
- 总览缓存N、R、比例、重建状态和修士统计对应的文本；未变化时复用字符串。
- DSH只读审查完成并已关闭，未发现本轮确定性计数回归；按其发现补齐猫宝快照放置完成后的登记/专用通知，新建和已登记人物都立即计入。此补丁由主智能体完成针对性回归。

自然配额公式、5—6岁一次性判定、特殊来源、存量保护、稳定排序、候选去重、每次最多32人及年度共享预算保持。没有新增C#文件、配置、依赖、公共API或存档字段；RootAgeEligible仅属于运行时Entry。
