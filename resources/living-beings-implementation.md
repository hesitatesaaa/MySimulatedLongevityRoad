# 生灵与战斗职业实施记录

基线：本仓库当前 0.6.0 工作目录，保留已有修改。目标：WorldBox build 115 / NeoModLoader。

## 固定需求

- 生灵栏目：妖兽、具名生物、智慧生物三目录；玄黄族仅手动首次放置。
- 玄黄族：人类原生 AI、繁殖、文明、分层人物资源、19 项风格建筑与 6 项公共建筑订单、三类船只。
- 六职业：剑修、武修、术修、符修、阵修、灵契师；各五阶，每阶一主动一被动。
- 40% 独立先天潜质；师承/宗门10%、遗迹15%、五年训练后自悟5%；每年只判一次。
- 经验阈值 0/200/500/900/1400；训练8/年，实战额外至多4/年；试炼10/25/50/80。
- 六职业特质、三十被动特质、三十主动图标，均64像素；主动不加特质，潜质只在右侧档案显示。
- 档案下方：列传与技能切换等宽，间隔6像素；顶端保留修士档案；技能视图只展示本职十项。
- 玩家强制转职继承阶位经验、清试炼、熟练度重练；删除职业清进度、保留潜质并可重新入职。
- 还真/猫宝完整继承；修为不足停用高阶；蓄力打断损失20%灵力、不耗物品、失败冷却3秒。
- 三十主动独立完整动画，触发被动短效；匹配现有像素修仙风；使用原版音效。
- 直接扩展现有接口，不加兼容框架和防御性兜底；只运行必要验证。
