# 妖兽与攻击法术整合更新实施记录

当前为开发预览，目标版本 0.6.0。代码可以使用实际 WorldBox／Unity 程序集编译；本记录不代表游戏内验收通过。

## 已接入

- 普通／具名妖兽分流；普通妖兽两个形态均无智慧、无文明、无自动繁殖，元婴化形独立于智慧。
- 普通妖兽本能修炼、突破、寿命、境界属性和天赋攻击；排除人物家族、师徒、职业、坊市、冒险及世界魂资格，不占人物境界席位。
- 区域栖息地索引、地形失效通知、年度审计、常见补充与条件稀有出现；自然生成队列和年度游标保存。
- 七级兽潮权重、境界解锁、四类主题、首领／精英／普通构成、容量预留、分帧生成、阵营和进攻目标、事件记录及设置窗口。
- 真实死亡后的兽材奖励、来源与召唤主人追溯接口、确定性掉落、去重、背包锁定重试和待发奖励保存。
- 16 件通用兽材、21 种专属材料（朱雀火羽复用 M25）、75 件产物及 75 个数量配方。
- 多材料预检与扣除、原版资源别名合并、配方知识、材料预留、采购计价、配方说明、使用与装备效果。
- 妖丹可等量替代同阶妖血，基础配方及产物数量保持不变，说明显示替代选项。
- 攻击事件的单次施法、主目标优先、敌我过滤、目标锁定、延迟命中、一次结算、持续伤害来源、持久化冷却及待命中记录。
- 三阶段特效资源接口、朝向、追踪、游戏模拟时间、对象池与缺图时预览回退。
- 新增资源清单与生产目录／配方逻辑测试，正式发布检查要求资源和实机证据。
