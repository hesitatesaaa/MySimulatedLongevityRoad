# 四职斗法开发预览

本地源码实现，维持0.6.0版本号与仅新存档约定。未安装到游戏目录，未提交或推送。Unity启动、游戏内显示尺寸、CPU/GPU内存及100/500/1000单位压力验收仍待实测；编译、替身测试和图片检查不代表这些项目通过。

## 玩法与操作

保留原26门法术及其获取规则，新增C001—C016共16门技能。一主职加兼修，生产职业独立；金丹核心、化神神通须学习后才能施放。异职高阶技能保留在学习记录中并休眠，换职不清冷却。

- 剑修：掠影步、回锋诀、分光连斩、天门落剑。
- 体修：崩山靠、金罡架、撼岳三叠、法相镇岳。
- 五行术修：凝元弹、移形护元、五行连诀、五行天轮。
- 御兽师：灵契唤影、御灵标记、灵契护主、万灵奔袭。

基础法门可由自然修行、拜师、宗门任务、探索及法门卷获得；首次基础法门确定主职。自然修行每年20%尝试学习本职尚未学会的一门基础技，未入门时按功法、灵根、资质、宗门和角色固定种子选职。成功宗门委托和遗迹探索各有15%获得一门符合境界的本职传承；师徒可传授自己已学且学生境界允许的技能。已有技能可以制卷并进入现有市场流程。

核心战斗领悟须两门本职基础技达到10级；神通领悟须本职核心达到10级。只在至少20秒的境界差不超过一阶的真实敌对交战结束后判定，分别为5%与1%，每场最多判定一次。低阶交战和投影造成的伤害不累加合格时间。未学新技能不能通过无传承的自行研习直接生成。

法术录顶部四个特质图标可手动指定主职；赋予职业特质也可指定主职，不赠送技能。法术录保留原玩家手动授予技能功能，新职业技能仍检查境界。技能说明包含获取条件；人物背包/能力列表显示高阶技能休眠状态。

## 战斗表现与边界

前摇、释放、命中、收势使用模拟时钟。普通前摇0.12—0.25秒，核心0.4秒，神通0.85秒；同一角色仅一个主动动作。普通攻击仍可作为无合适技能时的行动。选招按生存、敌方蓄力、距离、敌群、主职、灵力和重复惩罚评分。

动作参考战斗之神的闪步、错身连斩、上挑砸地、蓄力/弹道/光束、范围预告、护主与兽群冲锋；由当前角色/妖兽图片的渲染副本、像素轨迹、法阵和残影编排实现。角色真实移动只使用检查过的短距离地面位移，渲染副本不改原角色物理与动画。没有全局时停、自动追踪镜头、新人物图片或新特效图集。

五行连诀只组合已学、可负担且不在冷却的法术，最多三段，同时支付连诀和各段法术灵力并进入各自冷却。连控最多1.2秒，随后2秒保护期内硬控降为减速。前摇被打断不退款、不刷新冷却；已释放独立弹道在施法者死亡后继续结算，引导技能终止。目标阵营在每次命中时重新检查。

灵契是轻量战斗投影，不是Actor，不参加人口、繁殖、国家、掉落和兽潮。使用现有白虎、青鸾、玄武、青龙图片及动画，青绿轮廓区分。境界上限1/1/2/3/3/4/4，持续30秒；击杀归主人。护主消耗投影耐久分担一次伤害；换主职立即清理。基础唤影允许兼修。万灵奔袭的额外副本只演出。

设置“斗法地形破坏”：0关闭、1仅痕迹、2完整，默认2。元婴/化神/合道/长生重招破坏半径上限2/3/4/5格；圆形格点每招处理一次，队列分帧执行。建筑无差别波及，包括己方建筑；单位仍只伤敌人。普通连击不逐段毁地。完整模式尊重原生Gaia保护检查；痕迹模式只调用烧痕接口。

同屏法术、残影、像素轨迹、灵契及轮廓共享96个特效预算，装饰最多占用72个，命中与范围阶段保留余量。镜头外关闭投影渲染，模拟与伤害照常；投影按主人索引查询，每帧最多处理64个投影、32个战斗角色及有预算的地形格。

## 存档与资源

主职及学习记录、冷却保存在人物自定义数据；施法队列v2兼容读取v1条目。保存已经结算的目标、段数、恢复阶段，命中回调内保存不会重放已结算伤害。战斗场次、控制保护、架势、投影到期时间与下次攻击时刻、地形处理游标保存为独立版本键。投影渲染对象与短时轨迹不写入存档。

新图片仅GameResources/trait/MclslBattleSword.png、MclslBattleBody.png、MclslBattleArts.png、MclslBattlePact.png。均由内置image_gen分别生成，缩放为透明64×64；来源、提示主题、约束及输入输出SHA256见battle-icons.manifest.json。人物和48份既有法术阶段图集继续复用。

## 复核命令

先运行 `.dev-tools/battle-tests/prepare.py`，再运行 `dotnet run --project .dev-tools/battle-tests`。prepare仅原样摘取生产文件中的地形队列及支付方法，以便与真实施法队列、职业、控制和灵契源码一起在替身环境执行；不会生成游戏生产源码。

完整编译使用 `tools/build-release.ps1 -LocalDevelopment -PythonExecutable <含Pillow的Python>`。附加资源与接线校验使用 `tools/validate-battle-combat.py`。正式发布门禁维持原设置，不将开发预览标为Unity验收完成。
