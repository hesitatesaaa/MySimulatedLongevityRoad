# 0.8.1 开发者包说明

本包以用户提供的 0.8.1 玩家包以及其后的边框、召唤妖兽、一级住房和世界概览特效更新为基线，版本号保持 0.8.1；建筑影子沿用基线。

运行源码和素材来自更新后的 0.8.1 玩家包。包内图片沿用该基线已有的编码与尺寸，打包时未重新量化或缩放；当前未取得该版玩家包压缩前的完整原始图片，因此不能把本包当作压缩前的完整美术素材备份。

开发者角色编辑器，以及玩家包中缺少的 tools、resources、AGENTS.md 和 .gitignore，从本机既有 0.8.0 开发工作区补充；与 0.8.1 基线同名的文件均保留基线版本，编译检查脚本除外：其源码路径过滤和零源码误报已修正。补充的旧版脚本和资料可能只适用于 0.8.0，其中 tools/package-release.py 的版本检查面向 0.8.0，不能直接当作 0.8.1 打包脚本使用。不要将历史验收记录当作本次 0.8.1 的实机验收结果。

开发者包启用角色编辑器和调试入口，其中部分按钮会改变世界状态。编辑器窗口版本号已更新为 0.8.1；切换世界后，使用 F8 前请先重新选择当前世界的人物。玩家包原有的 verification-0.8.1.json 记录的是 274 个玩家源码文件，本包 278 文件的编译结果见 FILE-MANIFEST.json。

源码编译检查：278 个 C# 文件（含开发者角色编辑器）使用本机 WorldBox 0.51.2/build 115 依赖编译通过，有既有编译警告。游戏内画面与实际运行尚未验证。可按本机环境配置 GameRoot 后使用 tools/compile-check.ps1 进行源码编译检查。

本次性能优化以更新后的 0.8.1 开发者包为基线，减少年度经济计划、市场库存统计及档案补齐的重复工作，合并共享反射写入与排行名称解析；详见 resources/performance-optimization-20261030.md。未进行游戏内性能复测。

> 实时指标（源码文件数/行数/编译警告/catch 统计等）以 docs/CODE-METRICS.json 为准，由 tools/report-code-metrics.py 生成；上文手写数字可能滞后。
