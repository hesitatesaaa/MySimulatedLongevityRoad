# 真实引擎诊断

这些 C# 文件仅放入工作区内独立的 WorldBox/NML 测试副本，不能复制到生产 `code`、打入预览包或安装到用户正在使用的游戏。各入口通过 `MCLSL_BEAST_*_PROBE` 环境变量启用，创建新测试地图，报告写入工作区，完成后退出该诊断进程。

- RuntimeProbe：21 种化形、图集加载、七级生成、真实击杀与飞球兽炼制闭环、独立播种市场库存交易、背包/配方/未完成兽潮磁盘恢复。
- SpellProbe：生产 `TryCastCombat`、原生 `getHit`、模拟时间、阶段对象、暂停/瞬移、离屏/池满/关闭、转友方/施法者死亡、原生倍速、待命中法术磁盘恢复。`prepare-spell-probe.ps1` 仅在独立副本注入伤害观测回执，原生攻击只对诊断单位关闭。`MCLSL_BEAST_SPELL_PROBE_FOCUS=edges` 跳过已验证的 16 个施法，检查新增边界。
- RecipeProbe：111 件图标从游戏注册目录加载；75 配方逐一验证不足时不部分扣除与足料时精确扣除；25 法宝装备；50 消耗品使用与扣除；真实年份的自动使用品阶/库存限制。库存与知识为诊断播种，年份参数逐配方前进，不是自然学习或长期职业成长证据。
- DeathProbe：真实原生死亡路由中的自然死因、编辑删除、环境伤害、正常击杀、致命伤后额外命中及原生受击抖动。测试主动触发原生死因，并非等待自然寿元耗尽。

`summarize.py` 严格核验选定报告并保留原始报告 SHA256。失败和中止报告不删除；某报告的前半检查成功不代表整个报告通过。诊断源码不作为游戏服务替身，但受控场景、播种库存、明确故障输入与关闭诊断单位原生攻击必须注明。

全部诊断均不能替代正常 AI 实战、实际完整视觉审看、100/500/1000 单位各两分钟、二十分钟持续运行、对应基线和 CPU/GPU 内存比较。`unityValidation`、`gameplayCasesPassed` 与 `releaseReady` 不因此改为通过。
